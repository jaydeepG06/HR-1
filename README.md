
# HR Data Analysis & Employee Burnout Prediction

## Project Overview
This project explores employee data to understand workplace factors affecting employee stress and burnout.

The analysis uses Python and data analysis libraries to identify patterns and relationships among employee characteristics, working hours, satisfaction, stress levels and burnout.

## Dataset Information
- Total Records: 2,000 employees
- Age
- Gender
- Job Role
- Experience
- Work Hours Per Week
- Remote Ratio
- Satisfaction Level
- Stress Level
- Burnout

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Objectives
1. Explore employee demographics and job roles.
2. Analyse working hours and employee stress.
3. Investigate employee satisfaction levels.
4. Examine factors associated with burnout.
5. Apply statistical analysis and machine learning techniques.

## Project Files
- `HR data analysis.ipynb` – Jupyter Notebook containing the analysis.
- `synthetic_employee_burnout.xls` – Employee dataset.
